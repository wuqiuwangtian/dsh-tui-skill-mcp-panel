# ADR-0002：MCP 启停精确编辑 disabled，迁移旧覆盖

- 状态：已采纳（用户于 2026-11-11 明确授权，D-12）
- 关联：[需求 FR-10 / AC-15](../需求文档.md)、[完整 UI 失败证据](../release-readiness.md#11-webtui-完整-ui-顺序共存)
- 替代范围：ADR-0001 中“追加本插件 disabled 覆盖”的写法；patch/loader 主路径及锁、备份、冲突保护继续有效。

## 原因与选择

web 2.3.7 只用带模块名的定义行显示和修改开关，忽略后续无模块名的覆盖。旧 TUI 在原始定义保持 `disabled: true` 时追加 `disabled: false`，DSH 实际运行但网页显示停用；网页停用也会被旧覆盖抵消。仅刷新或共用锁不能解决。

选择在本项目精确修改 profile 定义的普通布尔 `disabled`，允许插入/删除该字段；不重输出整份 YAML，不扩展原始行的配置编辑/删除，不改第三方已安装包。保留原边界则 AC-15 受阻；另一方向是由 web 上游支持完整 patch 组合语义，但本项目不能以修改用户已安装包交付。

## 编辑与旧数据

- 按 id + serverName 唯一定位带 MCP 模块名的定义，拒绝重复定义或外来同 id 覆盖。
- 已有布尔字段只改标量；启用时可移除无附加注释的独立字段。插入时保留原缩进/CRLF。带行内注释的字段保留注释；表达式、别名、锚定 disabled、非布尔值、缺字段的 flow mapping 等无法安全处理的格式拒写。
- 对目标启停时，候选文本同时修改定义并移除本插件对应旧两字段覆盖；保留其他行、外来字段和独立注释。旧目标行带附加注释/特殊结构时拒绝自动删除，留给手工合并。
- MCP 页显示旧覆盖数量；`m` 和鼠标迁移按钮打开目标/保存状态预览，确认后整批迁移。保留每条覆盖保存的状态；任一目标有歧义或 home 配置则整批失败，无部分写入。打开/刷新面板不写文件。
- 迁移及启停沿用 `<patch>.panel.lock`、profile/home 快照检查、完整原文私有备份与原子 rename；候选校验和备份失败均停止。
- 确认绑定预览时的 profile/home 路径及内容快照，即使确认期间 runtime 已刷新也拒绝提交新目标。围栏内有外来行时保留它们及围栏，迁移完成以旧受管覆盖数量为准。

## 后果与验证

原始定义的启停字段可能改变，不再承诺所有原始字节都不动；其他内容仍保真。后续文件变更会使旧删除撤销快照过期，应拒绝整份覆盖恢复。降级旧 TUI 可能再次生成覆盖，需重新迁移。

验证覆盖旧覆盖迁移、三种行来源（原有/TUI 新增/web 新增）的双向开关、实际 loader/工具状态，及表达式/注释/别名/重复目标、锁/冲突/备份失败、删除撤销。web 的空值渲染崩溃和技能组无锁写入为独立边界，不能据此宣称修复。
