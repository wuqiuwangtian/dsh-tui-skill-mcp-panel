在 dsh-TUI 输入 `/skill-mcp`，即可管理当前工作区和全局的技能，以及当前 profile 的 MCP 服务器。首版支持技能筛选、启停、本地导入、分组、软删除和撤销；MCP 可精确启停，本面板新增的 stdio 和 Streamable HTTP 配置还可编辑、删除和撤销。已有 profile 行仅可启停，home 层只读。

## 安装

在已安装 dsh-TUI 的 profile 中执行以下命令。示例 profile 名为 `dsh-tui`，自定义安装请换成实际名称。插件与宿主同进程运行，安装前请核对来源。

```sh
dsh plugin --profile dsh-tui add dsh-tui-skill-mcp-panel@0.1.0
dsh --profile dsh-tui
```

也可下载本页附件 `dsh-tui-skill-mcp-panel-0.1.0.tgz`，在下载目录运行 `dsh plugin --profile dsh-tui add ./dsh-tui-skill-mcp-panel-0.1.0.tgz`。首次安装时包管理器可能仍需联网获取依赖。进入 TUI 后输入 `/skill-mcp`，按 `?` 查看操作帮助。[npm 版本页](https://www.npmjs.com/package/dsh-tui-skill-mcp-panel/v/0.1.0) · [完整使用说明](https://github.com/wuqiuwangtian/dsh-tui-skill-mcp-panel/blob/v0.1.0/README.md)

**从源码开发版升级**　如果 profile 包含你手写的 loader 行覆盖，请先按包名确认归属。TUI 的 loader 行从 `skill-mcp-panel` 改为 `dsh-tui-skill-mcp-panel`，仅需迁移确认为 TUI 的覆盖。web 可以有旧同名行，请保留。命令、场景和分组、备份、回收站目录沿用原值。

## 支持范围

- **本地 TUI** 主支持 dsh-TUI `0.20.2` / DSH `0.2.2-rc.5`，在 Linux/WSL2、Node `26.3.0` 验证 inline 和 fullscreen。保留 `0.19.0` / `0.2.2-rc.1` 已验证的安装、启停等路径。
- **MCP 连接** 已测 stdio、本机 Streamable HTTP、认证头与环境变量引用。私有远端 TLS、代理和断网重连未验证；OAuth 与面板内连接测试未纳入首版。
- **数据保留** 普通技能删除批次默认保留 7 天、最多 100 批。MCP YAML 备份、待撤销的 MCP 删除清单和技能分组备份持续保留，可能增长。撤销需要原路径的原始备份。卸载插件会保留这些数据。[备份盘点和撤销说明](https://github.com/wuqiuwangtian/dsh-tui-skill-mcp-panel/blob/v0.1.0/docs/release-readiness.md#45-只读盘点-mcp-备份2026-11-20)

## 已知限制与恢复

1. **共享技能分组一次只用一端编辑**。web 2.3.7、2.3.12、Git v2.3.16 的旧页面都能覆盖 TUI 刚加入的成员。切换编辑端时先重新加载网页，或在 TUI 按大写 `R`。普通技能和 MCP 已验证可顺序操作、刷新互读。
2. **部分手写多行 flow YAML 会被 web 拒写**。上述三版测试中文件保留原样。避开 web 对该行的写入；原有 profile 行可在 TUI 权限范围内启停。
3. **web 2.3.7 切换 MCP 后可能丢失卡片**。配置可能已更新，先重载再核对，避免反复切换。2.3.12 和 Git v2.3.16 在该项复测中正常。
4. **停用冷启动的 Node stdio MCP 后，终端可能回显或按键失效**。停止输入，优先正常退出并重启 TUI。已回到 shell 且终端仍异常时再用 `stty sane`。[终端故障速查](https://github.com/wuqiuwangtian/dsh-tui-skill-mcp-panel/blob/v0.1.0/docs/release-readiness.md#115-已知问题速查与处理入口2026-11-12) · [三个 web 版本的测试结果](https://github.com/wuqiuwangtian/dsh-tui-skill-mcp-panel/blob/v0.1.0/docs/release-readiness.md#46-ac-15-的三个-web-版本对照2026-11-20)
